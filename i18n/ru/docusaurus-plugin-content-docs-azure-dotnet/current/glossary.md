# Глоссарий

Здесь собраны определения всех терминов, которые вводятся в уроках. Строка **Новые термины** в конце каждого урока ведёт к его группе. Глоссарий пополняется вместе с курсом.

Проверено на 17.10.2026. Источники каждой группы приведены в разделе «Источники» соответствующего урока.

## Как устроен Azure \{#how-azure-is-organised}

**Тенант (tenant)** — экземпляр Microsoft Entra ID, в котором хранятся удостоверения организации и объекты каталога.

**Группа управления (management group)** — область действия общих правил Azure, объединяющая подписки или другие группы управления. Назначения прав доступа и политик могут распространяться вниз по этой иерархии.

**Подписка (subscription)** — область администрирования ресурсов Azure, в которой накапливаются начисления за потребление сервисов в рамках соответствующих условий оплаты.

**Группа ресурсов (resource group)** — контейнер для ресурсов Azure с общим жизненным циклом, включая их последующее удаление.

**Ресурс (resource)** — объект, которым управляет Azure: например, среда для запуска приложения, учётная запись хранения или база данных.

**Поставщик ресурсов (resource provider)** — служба Azure, которая предоставляет типы ресурсов и обрабатывает операции с их экземплярами.

**Область действия (scope)** — набор ресурсов Azure, на который распространяется назначение настройки управления, например роли или политики.

**Идентификатор ресурса (resource ID)** — полный идентификатор ресурса Azure. Он включает области действия и путь к поставщику, которые определяют место ресурса в иерархии управления.

**Azure Resource Manager (ARM)** — общий слой развёртывания и управления в Azure, который принимает запросы управления и направляет их поставщикам ресурсов.

**Плоскость управления (control plane)** — операции создания, настройки и удаления ресурсов.

**Плоскость данных (data plane)** — операции использования сервиса, который предоставляет ресурс: например, чтение BLOB-объектов или запрос к индексу.

**Регион (region)** — географическая область с центрами обработки данных Azure и обслуживающей инфраструктурой, в которой можно развёртывать региональные сервисы.

**Зона доступности (availability zone)** — отдельная группа центров обработки данных внутри региона Azure. Зона независима от других по электропитанию, охлаждению и сети.

**Зональный ресурс (zonal resource)** — ресурс, развёрнутый в выбранной зоне доступности.

**Ресурс с избыточностью между зонами (zone-redundant resource)** — ресурс, который сервис реплицирует или распределяет по нескольким зонам.

**Тег (tag)** — метаданные в виде пары «имя — значение», назначаемые ресурсу Azure, группе ресурсов или подписке для организации ресурсов и учёта расходов. Ресурсы не наследуют теги группы автоматически.

**Бюджет (budget)** — целевое значение расходов или потребления для заданной области действия и периода. При достижении настроенных порогов отправляются уведомления; потребление не останавливается.
