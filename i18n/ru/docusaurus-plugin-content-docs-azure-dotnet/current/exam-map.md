# Какие темы экзаменов разобраны в курсе

Пользуйся этой картой вместе с действующими руководствами по подготовке к [AI-103][guide103] и [AI-200][guide200]. Чтобы найти пробелы в подготовке, пройди пробный тест: [для AI-103][practice103] или [для AI-200][practice200]. Эти ссылки опубликованы на официальных страницах сертификаций; для доступа к тестам нужно войти в учётную запись.

Каждая строка таблицы соответствует одному пункту официальной программы экзамена. Выделенное полужирным название группы навыков относится ко всем строкам до следующего такого названия. Статусы показывают, насколько полно тема разобрана в курсе:

- **Разобрано** — курс объясняет, как выбирать сервисы или проектировать решение, а для настройки и разработки даёт инструкции, охватывающие весь пункт. Пошаговые указания могут обходиться без полноценной лабораторной работы и запуска в Azure.
- **Частично** — разобрана лишь часть пункта либо реализация объясняется на уровне понятий, без инструкций. В примечании указано, что ещё предстоит изучить.
- **Не разобрано** — нужная работа в курсе не объясняется; упоминания или сравнения сервисов не считаются инструкцией по её выполнению.

Недостающие темы изучай по ссылкам на Microsoft Learn. Самостоятельно выполняй задания и по темам со статусом «Разобрано», для которых в курсе уже есть пошаговые инструкции.

Обозначения проектов ведут к этапам сборки: [P1 — RAG-сервис][project-P1], [P2 — Агент за AI-шлюзом (AI gateway)][project-P2], [P3 — Конвейер приёма документов (ingestion pipeline)][project-P3]. Ограничения по запуску указаны в самих руководствах.

Руководство AI-103 предполагает, что у тебя есть опыт разработки приложений на Python, а руководство AI-200 — что ты уверенно владеешь Python. Проекты курса написаны на C#. Карта исходит из того, что принципы выбора сервисов, работы с удостоверениями, поиска и эксплуатации можно применять и с [Azure SDK for .NET][dotnetazure]. По каждой теме самостоятельно пиши код на Python, в том числе если она помечена как разобранная.

## Что изучить дополнительно \{#gaps}

Текстовый RAG-сервис, агент в собственном приложении и конвейер обработки документов не охватывают целиком ни один из двух экзаменов. Запланируй отдельную работу с Microsoft Learn для всех пунктов «Не разобрано» и недостающих частей пунктов «Частично». Примечания в таблицах уточняют объём этой работы.

- **AI-103: компьютерное зрение.** По [материалам Microsoft Learn][vision] отдельно пройди генерацию и редактирование изображений и видео, рассуждения по визуальным данным, подписи к изображениям, описания для доступности, извлечение визуальных характеристик, анализ видео, режимы Content Understanding, распознавание объектов и областей, а также защиту при работе с визуальным содержимым.
- **AI-103: язык и речь.** По [схемам обучения][language] изучи, как извлекать сущности и темы, составлять сводки, получать структурированные результаты анализа текста, определять тональность и тон, анализировать чувствительное содержимое и адаптировать результаты под предметную область. Отдельно отработай перевод текста, речевой ввод и вывод, собственные модели речи, рассуждения по аудио и перевод речи.
- **AI-103: приложения Foundry.** [Модуль Foundry SDK][sdklearn] и [модуль подключения к проекту][projectlearn] объясняют интеграцию с клиентом проекта; [материалы об агентах][agentlearn] — реализацию управляемых агентов и систем из нескольких агентов. В [курсе AI-103][learn103] дополнительно изучи выбор и использование других семейств моделей, конвейеры рассуждений, подбор промптов и параметров, рефлексию, самокритику и оркестрацию моделей и рабочих процессов.
- **AI-103: эксплуатация и извлечение информации.** Отдельной работы требуют CI/CD для проектов Foundry, полноценная частная сеть, мониторинг дрейфа и состояния индексов, настройка политик и сигналов безопасности, оценка безопасности и средства объяснения результатов, наборы навыков для обогащения, приём данных помимо документов и семантическое извлечение полей. Начни с [курса AI-103][learn103]; конкретные недостающие части указаны в таблицах.
- **AI-200: размещение приложений.** По [курсу AI-200][learn200] отработай использование ACR Tasks, развёртывание контейнеров в App Service, настройку правил KEDA для масштабирования по очередям и событиям, работу с манифестами и диагностику AKS. Масштабирование по HTTP и работа с ревизиями Container Apps решают другие задачи.
- **AI-200: данные.** По [материалам AI-200][learn200] отдельно выполни запросы через Cosmos DB SDK, настрой индексы, оптимизируй расход RU, реализуй векторный поиск и обработку канала изменений. Для PostgreSQL нужны векторные индексы, подбор ресурсов для векторной рабочей нагрузки, RAG с фильтрами и оптимизация соединений; для Redis — клиентские операции и векторные индексы. Хранилище одобрений P2 в PostgreSQL и записи заданий P3 в Cosmos DB используются для других целей, чем упражнение с векторной базой.
- **AI-200: интеграция и безопасность.** Отдельно реализуй отправку в темы и получение из подписок Service Bus, собственные события Event Grid, HTTP API на Functions, полный цикл ротации секретов Key Vault и интеграцию клиента App Configuration. Материалы — в [курсе AI-200][learn200].

Для обоих экзаменов к каждой теме добавь практику на Python, включая пункты «Разобрано».
